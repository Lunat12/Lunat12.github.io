TECHNICAL CASE STUDY · RENDERING SYSTEMS

Trail and Line Rendering Systems

I developed two rendering components for our custom DirectX 12 engine: a Trail Component that creates visual effects from an object's movement, and a Line Renderer that draws configurable lines between points, including points attached to moving objects.

Trail Component

I implemented a Trail Component based on techniques covered in our graphics programming course. The component records the positions and rotations of a moving object, adding new points when a minimum distance threshold is reached and removing them after their configured lifetime.

It generates ribbon geometry from these points using vertex pairs and indexed triangles, with configurable width, color gradients, textures and bloom support.

For the editor integration, I adapted existing tools from our engine, including the gradient and Bézier curve editors.

Why a separate Line Renderer?

The game's central Bound mechanic required a persistent visual connection between two moving characters. Since the Trail Component generates geometry from an object's previous positions, it wasn't suitable for maintaining a connection between two objects.

Inspired by Unity's Line Renderer, I developed a separate component that supports manually defined points or points linked to GameObject transforms. The line updates its geometry using the current positions of those points, allowing it to maintain a connection as the objects move.

The component also supports individual point widths and configurable color gradients.

Color Gradient Interpolation

To support smooth color gradients along the Line Renderer, I calculate the cumulative distance at each point and normalize it against the total line length.

Both vertices at each point receive this normalized value. The vertex shader passes it through, and the GPU interpolates it across the triangles. In the pixel shader, I use the interpolated value to identify the surrounding gradient color marks and blend their colors.

I implemented this approach following advice from my teacher, who suggested using an interpolated value in the pixel shader to evaluate the gradient.

Future Improvements

For the Trail Component, I would like to implement Catmull–Rom interpolation to create smoother trails between sampled positions, as well as explore texture mapping that stretches a texture across the entire trail.

For the Line Renderer, I would like to implement camera-facing ribbon geometry. The current implementation uses a fixed world-up direction, which suited our game's top-down perspective but limits how the lines appear from other camera angles.
